专项工作 HTML 版 · 初始化与上云步骤
================================================================
目标：把 专项工作.html + data.json 推到 GitHub，开启 GitHub Pages
      拿到一个云端网址，手机/电脑随时录入，数据自动同步。

本文件夹已含：专项工作.html、data.json、同步脚本.bat
下面是你（唐总）本地一次性要做的 5 步。

----------------------------------------------------------------
第 1 步：安装 Git（若已装可跳过）
----------------------------------------------------------------
1. 打开 https://git-scm.com/download/win 下载安装，一路 Next。
2. 装完后打开「命令提示符」或「PowerShell」，输入：
      git --version
   能看到版本号即成功。

----------------------------------------------------------------
第 2 步：在 GitHub 建一个空仓库
----------------------------------------------------------------
1. 浏览器登录 https://github.com ，点右上角 “+” → New repository。
2. Repository name 填：zx-tracker （或你喜欢的英文名，纯英文）。
3. 选 Public（免费开启 Pages 需要 Public；私有也可但 Pages 仅你可见）。
4. 不要勾 “Add a README”，其它默认，点 Create repository。
5. 建好后页面会显示仓库地址，形如：
      https://github.com/你的用户名/zx-tracker
   记下「你的用户名/仓库名」这一串，第 5 步要用。

----------------------------------------------------------------
第 3 步：生成访问令牌（Token，一次性）
----------------------------------------------------------------
1. 浏览器打开 https://github.com/settings/tokens
2. 点 “Generate new token” → 选 “Generate new token (classic)”。
3. Note 填：zx-tracker ；Expiration 选 No expiration（或按需选）。
4. 勾选 scopes：把 repo 这一整组全勾上（控制仓库读写）。
5. 最底部点 “Generate token”。
6. 生成的令牌形如 ghp_xxxxxxxx，【立即复制保存好】，页面关闭后看不到。

   安全提示：令牌等于你仓库的钥匙，别发别人、别截图外传。
   它只存进你本机浏览器（设置页），不会写进文件。

----------------------------------------------------------------
第 4 步：把本文件夹推上 GitHub
----------------------------------------------------------------
在本文件夹地址栏输入 cmd 回车，依次执行（去掉括号说明）：

   git init
   git add .
   git commit -m "init 专项工作跟踪器"
   git branch -M main
   git remote add origin https://github.com/你的用户名/zx-tracker.git
   git push -u origin main

   若提示输入账号密码：用户名填你的 GitHub 账号，
   密码处【粘贴第 3 步的令牌】（不是登录密码）。

推成功后，GitHub 网页刷新能看到这 3 个文件。

----------------------------------------------------------------
第 5 步：开启 GitHub Pages（拿到云端网址）
----------------------------------------------------------------
1. 在仓库页面点 Settings → 左侧 Pages。
2. Source 选 “Deploy from a branch”，Branch 选 main，目录选 /(root)。
3. 点 Save。等 1~2 分钟。
4. 页面会给出网址，形如：
      https://你的用户名.github.io/zx-tracker/
   这个就是云端网址，手机浏览器收藏它，随时录入。

----------------------------------------------------------------
第 6 步：在网页里填设置（关键）
----------------------------------------------------------------
1. 电脑双击打开 专项工作.html（或手机开云端网址）。
2. 点右上角 “⚙ 设置”：
     访问令牌 Token：粘贴第 3 步的令牌
     仓库：填 你的用户名/仓库名（如 zhangsan/zx-tracker）
     数据文件路径：data.json（默认）
     分支：main
3. 点 “测试连接” → 提示成功 → 点 “保存设置”。
4. 从此录入自动写回仓库，手机/电脑实时一致。

----------------------------------------------------------------
日常使用
----------------------------------------------------------------
• 新建/修改：点“＋ 新建专项”或在表格点某行编辑。
• 看板：按状态、按负责人两种视角切换。
• 本周跟进：自动列临期/逾期/待决策，行变红=逾期、黄=3天内。
• 导出本周清单：开会前点一下下载 txt。
• 本地镜像：双击“同步脚本.bat”把云端最新拉到本文件夹。
• 提醒：纯静态无主动推送；要主动提醒可后续把令牌接入飞书/日历。

----------------------------------------------------------------
常见问题
----------------------------------------------------------------
Q：没填设置也能用吗？
A：能，但数据只存浏览器本地，不会同步。填了设置才上云。

Q：手机能直接录吗？
A：能。开云端网址（GitHub Pages），同样建/改，写回仓库。

Q：令牌泄露或想换？
A：GitHub → Settings → Tokens 撤销旧令牌，重发新的，回设置页更新。

Q：data.json 被我手改乱了？
A：仓库里可回看历史版本（GitHub 文件页面 → History）恢复。
