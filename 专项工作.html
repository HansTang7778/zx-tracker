使用说明

这是什么：一个单文件专项工作管理工具。数据存在 GitHub 仓库的 data.json 里，电脑和手机开同一个网页，录入都写回仓库，两边实时一致；你电脑文件夹里用「同步脚本」保持一份镜像。

第一次配置（一次性）：

  1. 点右上角 ⚙ 设置，粘贴 GitHub 令牌、填仓库名（用户名/仓库名），保存。
  2. 没配之前，数据只存在浏览器本地（localStorage），不会同步——配了才上云。

日常用法：

  1. 新建：点「＋ 新建专项」，填事项/类型/负责人/目标日/优先级/国家，提交即存。
  2. 修改/删除：总览里点任意一行打开编辑；底部「删除本条」。
  3. 跟进：「本周跟进」自动列出未闭环且临期/逾期/待决策的项；行变红=已逾期，黄=3天内到期。
  4. 导出：点「导出本周清单」下载 txt，开会用。
  5. 手机录：打开云端网址（GitHub Pages），同样能建/改，写回仓库。

本地镜像：双击 同步脚本.bat 把云端最新拉到本文件夹（需文件夹是仓库克隆）。

注：纯静态无主动推送提醒；令牌仅存本机浏览器。详见「初始化与上云命令.txt」。
